# ⚽ Football ERP

Sistema ERP para gestão estratégica de clubes de futebol.

## 🎯 Objetivo

O Football ERP tem como objetivo centralizar informações
esportivas, físicas, táticas e administrativas de um clube
de futebol em uma única plataforma.

O sistema está sendo desenvolvido inicialmente como um
projeto de estudo e portfólio, utilizando um clube real
como caso de demonstração.

## 🚀 Funcionalidades planejadas

- Gestão de jogadores
- Gestão da comissão técnica
- Planejamento de treinamentos
- Periodização estratégica
- Controle de carga de trabalho
- Gestão de jogos e competições
- Estatísticas e análise de desempenho
- Scouting
- Mercado da bola
- Notícias
- Integração com APIs externas
- Dashboards
- Relatórios
- Controle de usuários e permissões

## 🛠️ Tecnologias

- Python
- FastAPI
- Uvicorn
- SQLAlchemy
- SQLite
- PostgreSQL
- HTML
- CSS
- JavaScript
